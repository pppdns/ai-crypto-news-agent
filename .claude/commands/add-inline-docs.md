description: Add a file header summary and inline comments to the given file(s)
argument-hint: '[file paths]'
---

Add documentation to $ARGUMENTS (or, if no files are given, to the files changed on the current branch).

- At the top of each file, add a short JSDoc block summarizing the file's purpose and usage. Keep it focused.
- Add brief inline comments above the major sections of the code that say what each part does.
- Don't change behavior, and don't comment on the obvious.
